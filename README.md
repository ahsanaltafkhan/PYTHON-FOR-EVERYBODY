# Python for Everybody — Complete Learning Repository

A structured, hands-on Python learning path inspired by the public **Python for Everybody (PY4E)** curriculum.

## What is included

- 17 progressive modules
- Runnable Python examples
- Original practice exercises
- Mini-project scaffold for every module
- Networking, APIs, JSON, OOP, SQLite and visualization
- 4 capstone project templates
- Learning roadmap

## Curriculum

1. Why Programming
2. Variables, Expressions & Statements
3. Conditional Execution
4. Functions
5. Loops & Iterations
6. Strings
7. Files
8. Lists
9. Dictionaries
10. Tuples
11. Regular Expressions
