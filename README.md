# Python for Everybody — Complete Learning Repository

A structured, hands-on Python learning path inspired by the public **Python for Everybody (PY4E)** curriculum.

## What is included

- 17 progressive modules
- Runnable Python examples
- Original practice exercises
- Mini-project scaffold for every module
- Networking, APIs, JSON, OOP, SQLite and visualization
- 4 capstone project templates
- Learning roadmap

## Curriculum

1. Why Programming
2. Variables, Expressions & Statements
3. Conditional Execution
4. Functions
5. Loops & Iterations
6. Strings
7. Files
8. Lists
9. Dictionaries
10. Tuples
11. Regular Expressions
12. Network Programming
13. Using Web Services
14. Object-Oriented Programming
15. Databases
16. Data Visualization
17. Capstone Projects

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windows:

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
```

## Philosophy

Run the code. Change it. Break it. Debug it. Then solve the exercises without looking at the examples.
